## 2. 快速开始

**看界面**：双击打开 [`prototype/index.html`](prototype/index.html)（无需服务器、无需联网、无外部依赖）。
- 顶部工具栏 / URL hash 切换 5 屏：`#list` `#chart` `#entry` `#discover` `#mine`
- 真实可交互：底部 `+` 进入记账 → 选分类 → 按数字键盘 → 点「完成」，新记录会写入并回到明细页，统计页同步刷新
- 明细页点任意一行可看详情并**编辑 / 删除（含 3 秒撤销）**；点「10月 ▼」切月份；点眼睛图标隐藏全部金额
- 统计页可切 支出/收入、周/月/年、周期导航；点折线数据点看当日金额
- 我的页：备份与导出、数据恢复、分类管理、标签管理、安全锁、每周起始日、隐藏金额、关于

**读文档**：建议顺序 `01 需求 → 02 设计 → prototype 原型 → 03 计划 → 04 测试`。

**重新生成 Word**（可选）：
```powershell
$py = "D:\UserFiles\eavon.cai\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
& $py tools\md2docx.py docs\01-软件需求说明书-SRS.md deliverables\01-软件需求说明书-SRS.docx "01 · 软件需求说明书（SRS）"
```

## 5. 已知限制与不做的事

1. **本轮不产出可运行的安卓工程与 APK**。本机实测**未安装 JDK / Android SDK / Gradle / Flutter**（`03` `R-01` 已立项，`WBS-4.1` 第一步即安装 JDK 17 + Android SDK）。原型是用于需求与界面评审的高保真 HTML，不是安卓工程。
2. **Word 版面的视觉检查受限**：本机 DSH 自带的 LibreOffice 渲染器在把 DOCX 转 PNG 时，会把 A4 页面按约 1.19cm 宽布局（连一个仅含两段文字的最小对照文档也会右溢出 3.81cm），属于**渲染器缺陷**，与文档本身无关。文档侧已改用可机器验证的检查：`check_office.py` 结构校验 + 132 张表的 OOXML 宽度合规校验。请在 Microsoft Word / WPS 中做最终版面确认。
3. **原型与真实实现的差距**：原型用内存数组模拟数据、用 `<div>` 模拟原生控件，因此不测真实 SQLite 读写、SAF 授权、真机指纹、TalkBack 完整链路（`04` §1.3 已逐条排除）。
4. **分类图标为原创 SVG**，仅作形式参考；商用前需确认版权方案（`R-04`）。
5. **技术栈未定**，因此 `01` 的需求保持技术栈无关，`02` 的架构以 Kotlin+Compose 表述、并声明三方案同构。
