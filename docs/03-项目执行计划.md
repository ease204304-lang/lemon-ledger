## 3. WBS 任务分解

**计算规则与口径**
- 人日为公司内**净投入人日**（1 人日 = 1 名工程师 1 个标准工作日），不含会议与等待。
- `K+C 人日` = **Kotlin + Jetpack Compose** 原生技术栈估算；`Flutter 人日` = **Flutter** 跨端技术栈估算。两列同时给出，因 `TBD-02` 技术选型尚未拍板（见 `R-02`）。
- 任务粒度约束：**0.5 ≤ 单人日 ≤ 3.0**。
- 同一任务由两个角色共担时，人日按角色拆分后在 §9 分别计入。
- 输入列引用规则：`00§n` = `00-基线与术语.md` 第 n 章；`WBS-x.y` = 上游任务产物。
