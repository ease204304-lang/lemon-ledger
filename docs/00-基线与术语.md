## 1. 术语表

| 术语 | 英文/字段 | 含义 |
|---|---|---|
| 流水 | Transaction | 一条收入或支出记录，记账的最小单位 |
| 记账 | Entry | 用户录入一条流水的动作，对应「记账」页 |
| 分类 | Category | 流水的归属类别，分收入类与支出类；支持一级/二级 |
| 标签 | Tag | 用户的横向自定义标记，可与分类并存 |
| 账本 | Ledger | 流水集合；v1.0 仅「默认账本」一个 |
| 明细 | List | 按日分组的流水列表页，App 首屏 |
| 周期 | Period | 统计维度：周 / 月 / 年 |
| 已过天数 | Elapsed Days | 当前周期内从周期起始日到「今天」的天数（含两端） |
| 完整周期 | Closed Period | 已经结束的历史周期，已过天数 = 周期总天数 |
| 周期归属 | Period Membership | 一条流水按 `tradeDate` 归入唯一周期 |
| 软删除 | Soft Delete | 置 `deletedAt`，数据保留以便恢复与统计留痕 |
| 空态 | Empty State | 无任何流水时各页面的表现 |

## 6. 数据字段命名（唯一权威，`02` 展开）

```text
category(id, name, type[EXPENSE|INCOME], iconKey, parentId?, sortOrder, isBuiltin, isActive, createdAt, updatedAt)
transaction(id, ledgerId, type, amountCents:Long, categoryId, tagIds:String, tradeDateEpochDay:Int,
            note:String?, photoUris:String?, createdAt, updatedAt, deletedAt?)
tag(id, name, sortOrder, createdAt)
app_setting(key, value)          -- 货币符号 / 周起始日 / 默认记账类型 / 安全锁 / 备份目录
backup_meta(version, exportedAt, deviceModel, appVersion, checksum)
```

**强制规则**
- `BR-1.1` 金额一律以 **`Long` 分** 存储与运算，禁用浮点参与累加；仅在展示层格式化为 2 位小数。
- `BR-1.2` 日期一律以 **epochDay（本地日历日，无时区漂移）** 存储；跨时区不与 UTC 换算。
- `BR-1.3` 删除为软删除（`deletedAt`），统计与列表默认过滤已删除项。
- `BR-1.4` 分类停用（`isActive=false`）后不出现在记账页，但历史流水仍展示其名称与图标。
- `BR-1.5` 一级分类被删除时，其二级分类一并停用，不产生孤儿数据。

## 7. 统计口径公式（`01`/`04` 共用，已用参考图数据回归验证）

| 指标 | 公式 |
|---|---|
| 周期归属 | 按 `tradeDateEpochDay` 落入周期区间 `[start, end]`（含端点） |
| 周期总支出 | `Σ amountCents` where `type=EXPENSE` |
| 周期总收入 | `Σ amountCents` where `type=INCOME` |
| **周期平均值** | `总支出 ÷ 已过天数`，已过天数 = `min(今天, 周期末日) − 周期首日 + 1`；完整周期取周期总天数 |
| 分类占比 | `分类金额 ÷ 周期总支出`，输出保留 1 位小数百分比 |
| 分类进度条长度 | 按 `分类占比` 线性映射到轨道宽度 |
| 排行榜排序 | 金额降序；金额相同按 `sortOrder` 升序 |
| 折线图 y 上界 | 周期内单日金额最大值；单日最大值为 0 时上界取 `1.00`（即 100 分） |
| 折线图 x 轴 | 周视图 7 个自然日；月视图 1..月末；年视图 1..12 月 |
| **折线图日点值** | 该日 `EXPENSE`（或统计维度对应类型）流水金额之和；未来日期按 0 参与并渲染为空心点。**回归基准周期 `2026-10-05 ~ 10-11` 的日点值见下方实测表** |
| 未来日期 | `tradeDate > 今天` 的点渲染为空心点，值按 0 参与 |

**黄金算例（`04` 用作回归用例，数据源为附件统计页截图）**
- 周期：`2026-10-05`(周一) ~ `2026-10-11`(周日)，观测日 `2026-10-09`(周五) → 已过天数 = **5**
- 总支出 `2281.00` → 平均值 = `2281.00 ÷ 5` = **`456.20`** ✔（与截图一致）
- `818 ÷ 2281 = 35.9%`、`590 ÷ 2281 = 25.9%`、`434 ÷ 2281 = 19.0%`、`136 ÷ 2281 = 6.0%`、`99 ÷ 2281 = 4.3%`、`80 ÷ 2281 = 3.5%` ✔（六项全部与截图一致）
- 折线图 y 轴上界标注 `1045.00` = 当期单日最大值 ✔

**基准周期日点值（实测反解，`REF-1` 图区数据点质心）**

对参考图 3 的折线图区取样：顶部网格线 y≈773.7 对应标注值 `1045.00`；以 `10-05 = 1045.00`、`10-09 = 934.00`（后者由 REF-3 明细页当日小计独立确证）两点定标反解其余各日。

| 日期 | 数据点 y 坐标 | 反解值 | 基准值（用于数据集与用例） |
|---|---|---|---|
| 10-05 | 773.7（贴顶部网格线） | `1045.00` | **1045.00**（= 周期最大值，y 轴上界） |
| 10-06 | 1036.9 | ≈152 | **152.00** |
| 10-07 | 1053.2 | ≈96 | **97.00** |
| 10-08 | 1067.9 | ≈46 | **53.00** |
| 10-09 | 806.4 | `934.00` | **934.00** |
| 10-10 / 10-11 | 未检出（空心点） | `0` | **0.00**（未来日期） |
| 合计 | — | 2273（实测误差内） | **2281.00** |

> 硬约束：`2281 − 1045 − 934 = 302`，中间三日必须合计 `302.00`；实测三点之和 `294` 与约束相差 <3%（点质心定位误差 ±2px ≈ ±3.4 元），故取 `152 / 97 / 53` 使总额精确闭合。**九个分类金额不受影响。**
