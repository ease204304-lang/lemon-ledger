### B. 鲨鱼记账有, 柠檬记账没有 — **待实现** (v1.2)

#### B1. **预算系统** (核心缺失)
鲨鱼记账有:
- 日均预算 322.6
- 每天的净支出 vs 预算用 `绿/红` 圆点表示 (超 / 未超)
- 每天格子里直接显示 `净支出金额` (e.g. `-1045`)
- **快捷入口**: 5 个图标第 2 个是 "预算" (旗帜 icon)

> 我们的 5 入口里"预算"图标在, 但实际点击是 toast (占位)

**实现方案**:
- 新增 `budget` 表: (year, month, amount_cents)
- 每天计算: `net = 支出 - 收入`
- 颜色规则: `net <= 0` 绿, `net > 日预算` 红, 中间橙 (按鲨鱼记账的二值简化: 红/绿)
- 日历页每格显示净支出 + 圆点
- 月初可设置预算 (v1.2 加 UI, v1.1 后端先就绪)

#### B2. **单笔排行页** (大屏数据洞察)
鲨鱼记账点 "收入 3,697" 直接进排行页:
- 大字 "本月总收入 ¥27,225.00"
- 单笔收入排行 (按金额 or 按时间切)
- 每条: 图标 + 分类 + 占比% + 金额 + 日期
- 进度条 (黄色填充)

> 我们的"收入/支出"是死数字, 不能点进去

**实现方案**:
- 把 `_Stat` 改成 `InkWell`
- 跳转新页 `IncomeExpenseRankingPage({year, month, type: income/expense})`
- 复用 `CategoryIcon` + 进度条
- 数据源: `sumByCategory(type, year, month)`

#### B3. **快速记一笔 (bottom sheet)**
鲨鱼记账长按 + 按钮弹起 bottom sheet:
- 默认光标在金额输入框
- 类别选择 + 备注 + 推荐 tag
- 不打开完整页, 一键保存

> 我们的 + 按钮直接进完整 EntryPage

**实现方案**:
- 长按 + 0.5s 弹起 QuickEntrySheet
- 含类别 / 金额 / 备注 / 推荐 tag / 保存
- 短按仍打开完整 EntryPage

#### B4. **类别更多元 + 推荐 tag**
鲨鱼记账的 EntryPage:
- 12 个支出类别: 信用卡/餐饮/购物/日用/交通/蔬菜/水果/零食/运动/娱乐/通讯/服饰/美容/住房/**孩子**...
- 备注栏有 **相机 (拍照附件)** 和 **定位** 两个 icon
- 备注下方有"推荐"tag 横向滚动: 的士/业务招待/幼儿园伙.../轻食/M记/招...

> 我们 19 个支出类别, 但缺孩子/教育/住房/医疗 (重要), 缺推荐 tag, 缺附件/定位

**实现方案**:
- 类别增补: 信用卡/美容/住房/**孩子**/教育/医疗/通讯
- EntryPage 加 tag 推荐 (基于最近 5 笔同分类的备注)
- 加附件 icon (v1.2 调相册, v1.0 占位)
- 加定位 icon (v1.2 调系统位置, v1.0 占位)

#### B5. **带日历的数字键盘**
鲨鱼记账点日期 icon 弹起月份/日期滚轮, 选完直接嵌在数字键盘上方 (不切屏)

> 我们的 EntryPage 是单独 Dialog 选日期, 多一次交互

**实现方案**:
- EntryPage 顶部的日期 chip 改为可点
- 点开弹底部 sheet, 内嵌水平滚轮 (年/月/日)
- 选完直接关 sheet, 不切走 EntryPage

#### B6. **明细页日期格式**
鲨鱼记账: `10月10日 星期六` (含星期)
我们的 v1.1: `10月9日 星期五` (含星期) ✅ **已实现, 一致**

#### B7. **更多 (5 入口里的最后一个)**
鲨鱼记账的"更多"按钮展开二级菜单 (分类管理/币种/主题/字号/导出...)
> 我们的"更多"目前是 toast

**实现方案**:
- v1.2 弹底部 sheet: 分类管理 / 主题切换 / 字号 / 导出 / 关于
- 暂时只放 3-4 个核心项

### C. 鲨鱼记账没, 柠檬记账可以做

#### C1. **删除确认**

**柠檬记账可加**: swipe-left → "删除? 取消 / 确定" 弹窗 (推荐)

**柠檬记账可加**: 每天分组可点击日期行折叠/展开 (方便跳过老日期)
