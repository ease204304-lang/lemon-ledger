## 1. 应用概述

小猪记账是一款**个人记账 Android 应用**, 5 屏底部 tab 导航, 核心场景是"每天随手记一笔".

### 1.1 关键设计原则

| 原则 | 体现 |
|---|---|
| **录一笔 3 步完成** | 点分类 → 输入金额 → 按 = ( = = 保存 + 跳回首页) |
| **预算 = 用户每日所见屏** | 整页主体 ≤ 1/3 屏, 留出 2/3 给首页流水 |
| **实时反馈** | 选分类 → 立即黄色高亮; 输入运算符 → 实时求值预览 |
| **数据为本** | 金额用 `Long` 分 (无浮点), 日期用 `epochDay` (无时区漂移) |
| **本地优先** | SQLite 存储, JSON 备份/恢复, 无需账号无网络 |

### 1.2 适用人群

- 想要**简单快速**记账的用户 (反对复杂功能)
- 数据**安全敏感** (本地存储, 不上云)
- 喜欢**类鲨鱼记账**风格 (横排常用 + 全部网格)

## 2. 5 屏功能说明

### 2.1 首页 (明细)

**路径**: 点底部 `明细` tab

**功能**:
- 黄色 header 显示**当前月份汇总**: 收入 / 支出 / 月份切换
- 5 个快接入口: 账单 / 预算 / 资产管家 / 购物返现 / 更多
- 按**日分组**的流水列表: 停车费 -15, 餐饮 -9, 咖啡 -7, 充电 -62, 单车 -3
- 眼睛图标可隐藏/显示所有金额 (隐私模式)

**关键交互**:
- 点 10月 ▼ → 月份选择器
- 点眼睛 → 隐藏全部金额
- 上滑看更多历史

### 2.2 图表

**路径**: 点底部 `图表` tab

**功能**:
- 类型切换: **支出 / 收入** (右上角下拉)
- 周期切换: **周 / 月 / 年** + 上一周期/下一周期
- 数字卡片: **总支出 + 平均值** (大数字显示)
- 折线图: 当前周期的每日/每月/每年趋势
- 平均虚线: 显示当前周期平均 (作参考)
- 排行榜: 支出 Top N 分类, 横向进度条, 百分比

**统计口径** (基线定义):
- 平均值 = 周期总额 ÷ **已过天数** (而非周期总天数)
- 例如: 10-05~10-09 共 5 天, 总支出 2281, 平均 = 2281 ÷ 5 = **456.20**

**已知修复** (v1.5.1 hotfix):
- 折线图 Y 轴单位修复 (从 分 → 元), 旧 bug 会把折线压扁在 X 轴

### 2.3 记帐 (v1.6 核心)

**路径**: 点底部中央 `+` 按钮 (或底部 tab 的 `记帐`)

**布局** (3 步设计):

```
┌─────────────────────────────────────┐
│ × 关闭  │  记一笔                  │ ← 顶部 (60px)
├─────────────────────────────────────┤
│ 支出 / 收入  │ 📅 日期  │ 0 元      │ ← 状态 (35px)
├─────────────────────────────────────┤
│ [左: 14 分类网格 5×3] [右: 4 常用]  │ ← 选类 (234px, ≤1/5 屏)
├─────────────────────────────────────┤
│ 📝 备注 (输入后点 + 可保存为标签)      │ ← 备注 (30px)
├─────────────────────────────────────┤
│ 7 8 9 ×                              │
│ 4 5 6 −                              │ ← 数字键盘 (弹性填满,
│ 1 2 3 +                              │    约 700-1000px)
│ . 0 del =                            │
└─────────────────────────────────────┘
```

**3 步录一笔流程**:
1. **点分类**: 左网格 (14 个常用支出/收入) 或 右常用 (4 个 pinned 常用)
2. **输金额**: 数字键盘支持 1234567890 + 运算符 (`+` `−` `×` 无 `÷`)
   - **实时求值** (U2): 输 `1+2+` 立即显示 `3.00+`, 不需要按 =
3. **按 `=`**: 触发 `onEqualsAndSave` → 实时求值 + 写库 + 跳回首页
   - 没选分类 → snackbar "请选择分类"
   - 金额 = 0 → snackbar "请输入金额"

**关键交互**:
- **第 4 列整列品牌黄底** (运算符 + = 区分)
- `=` 加重品牌黄, 大字突出
- `.` 长按 = 语音录入 (录入自动填金额+分类+日期+备注)
- 备注输入后点右侧 `+` → 保存为标签

**设计来源**: v1.6.0~v1.6.4 共 7 次设计迭代 (U1/U2/U1.5/U1.6/U1.7/U1.8), 每次用户都给出新设计图

## 3. 关键技术特性

### 3.1 数据模型

| 表 | 字段 | 类型 | 用途 |
|---|---|---|---|
| `tx` | id, epoch_day, type, category_id, amount_cents, note, photo_path, created_at | 流水 | 核心流水表 |
| `category` | id, name, icon_key, type, sort_order, archived, pinned | 分类 | 19 支出 + 5 收入 |
| `budget` | year, month, amount_cents | 月预算 | v1.2 |
| `tag` | name, use_count, last_used_at | 标签 | 备注做关键词 |

**重要决策**:
- 金额 `Long` 分 (cents), 全流程无浮点
- 日期 `epochDay` (自 1970-01-01 起的天数), 无时区漂移
- JSON 备份兼容 v1.5+ (含 schema_version)

### 3.2 状态管理

- **本地 Provider** + **Riverpod** (themeProvider) (v1.6 引入 S1)
- 大部分用 `setState` (因为是单页, 不需要跨页共享)
- 跨屏共享: theme (light/dark) + font scale

### 3.3 性能

- 首页用 `ListView` + `GlobalKey` 滚动定位 (无卡顿)
- 图表用 `fl_chart` 0.69 (无 lag)
- 实时求值 < 1ms (只解析简单表达式)

## 5. 用户故事

### US-1: 早饭后记一笔早餐
> 用户 8:00 起床, 早餐花了 8.50 元. 打开 app → 点 `+` → 选 `餐饮` (常用) → 输 `8.5` → 按 `=` → 自动跳回首页. 流水 +1, 餐饮类累计 += 8.50.

**v1.6 优化**: 按 `=` 同时完成保存 + 跳回, **3 秒** 录一笔 (之前要按保存 + 跳走 2 步).

### US-2: 月末看月度报表
> 10-31 打开图表 → 切 `月` 周期 → 看总支出 2,281, 平均 114, 排行榜餐饮/交通/日用前 3. 切回首页, 10月所有流水按日排列.

### US-3: 重置数据 (防误触)
> 想重置测试, 进我的 → 重置数据 → 弹"危险操作"对话框 → 输入"确认" → 红色"执行重置" → snackbar "已重置, 请重启应用" → 回到首页 (空状态). **没有"确认" 2 字 → 按钮不可点**.

### US-4: 数据备份与恢复
> 我的 → 数据备份 → 选保存路径 → 拿到 `lemon_ledger_YYYYMMDD_HHMMSS.json`. 卸载重装 v1.6 → 我的 → 数据恢复 → 选这个 json → 选"合并" → 输"确认" → 流水全恢复.
