## 一、安装到手机

### 方式 A：直接传 APK（最简单，推荐）

1. 从电脑取安装包：
   `D:\DSH\Account\app\build\app\outputs\flutter-apk\app-release.apk`

2. 传到手机（微信/QQ 传输、数据线、或放到网盘/云盘后手机下载）：

   ```powershell
   # 如果手机通过 USB 连接且已开启 USB 调试，可直接推送安装：
   & "D:\07.DevWorkspace\android-sdk\platform-tools\adb.exe" install -r `
       "D:\DSH\Account\app\build\app\outputs\flutter-apk\app-release.apk"
   ```

3. 手机上点击安装包安装。首次会提示「禁止安装未知应用」：
   - 设置 → 应用 → 特殊应用权限 → 安装未知应用 → 选中你用的（文件管理/微信/浏览器）→ 允许
   - 返回后继续安装

### 方式 B：从本机直接安装到已连接的设备

```powershell
# 1. 确认设备已连上
& "D:\07.DevWorkspace\android-sdk\platform-tools\adb.exe" devices

# 2. 安装
& "D:\07.DevWorkspace\android-sdk\platform-tools\adb.exe" install -r `
    "D:\DSH\Account\app\build\app\outputs\flutter-apk\app-release.apk"
```

`-r` 表示覆盖安装（保留已有数据）。

### 注意事项

| 项目 | 说明 |
|---|---|
| **最低系统版本** | Android 5.0 (API 21) 及以上 |
| **包名** | `com.lemonledger.lemon_ledger` |
| **签名** | 当前 release 包用 debug 签名（可正常侧载安装，但不能上架应用商店） |
| **权限** | 记账 App 全部数据在手机本地，**不联网、无账号、无数据上传** |
| **卸载重装会丢数据** | 卸载后本地账本清空；升级请用「覆盖安装」 |

## 二、首次使用

1. **打开 App** → 首页是「记一笔」和账本总览
2. **记一笔**：点右下角 **「+」** → 选分类 → 输入金额 → 点「保存」
   - 金额输入界面：数字键盘位于下方圆形按钮位置，**双击日期可直接确认**
   - 分类网格支持**左右滑动**切换「支出 / 收入」
3. **记一笔后**：顶部快速栏有本周/本月/本年快捷筛选，首页按天分组显示

### 主界面结构（底部 5 个 tab）

| Tab | 功能 |
|---|---|
| **1. 首页** | 账本总览 + 按天分组的流水 + 快速筛选 |
| **2. 图表** | 统计图表（分类排行 / 标签统计 二级切换）、周/月/年、环比警示 |
| **3. +（中间）** | 记一笔 |
| **4. 发现** | 实用工具 |
| **5. 我的** | 主题、字号、数据备份/恢复、分类与标签管理、版本信息 |

## 三、日常使用要点

### 记账
- 金额必须 **> 0**；零和负数会被拒绝
- 分类固定**两级**：一级 + 二级（如 餐饮 → 午餐/晚餐/咖啡）
- 标签分**主标签 + 辅助标签**：一笔只能有一个主标签，主标签决定统计归属
- 交易对象（商户/来源）：收入填来源，支出填商户；全局对象库，可合并同类

### 统计（图表页）
- 顶部切换 **支出 / 收入**
- 下方 segment 切 **周 / 月 / 年**，可左右滑或点上方的历史偏移（上周/上上月）
- 二级视图：**分类排行 | 标签统计**
- 排行可按 **金额 / 笔数 / 最近时间** 排序，默认 Top 5，可展开全部

### 分类清单（v1.10.0 起，共 22 类）
- **支出 14 类**：信用卡、餐饮、娱乐、零食、交通、住房、旅游、医疗、运动、汽车、孩子、日用、投资、其他
- **收入 8 类**：工资、奖金、兼职、投资、利息、礼金、报销、其他

### 我的 → 数据备份
- **导出备份**：把账本导出为 JSON 文件保存到手机/网盘
- **恢复**：从备份文件还原
- ⚠️ 换手机务必先导出再导入

要让手机用上服务端统计，需要两步：

### 第 1 步：启动服务端


浏览器打开 `http://127.0.0.1:8000/docs` 可查看交互式接口文档。

### 第 2 步：让手机能访问到它

| 部署位置 | App 内填的地址 |
|---|---|
| 同一 Wi-Fi 下的电脑 | `http://电脑局域网IP:8000`（如 `http://192.168.1.10:8000`） |
| 模拟器（同机） | `http://10.0.2.2:8000` |
| 云服务器 | `http://公网IP:8000` |

查电脑局域网 IP：

```powershell
ipconfig | Select-String "IPv4"
```

### ⚠️ 还需要数据同步（当前未实现）

App 的账本数据存在**手机本地 SQLite**，服务端是独立空库。
要让统计页面显示真实数据，必须补一个**数据同步层**（App → 服务端增量上传）。

## 五、常见问题

**Q：安装时提示「应用未安装」**
A：多半是之前装过**不同签名**的版本。先卸载旧的再装：
```powershell
& "D:\07.DevWorkspace\android-sdk\platform-tools\adb.exe" uninstall com.lemonledger.lemon_ledger
```
（注意：卸载会清空本地账本，请先在「我的」里导出备份）

**Q：Android 提示「此应用可能有害」**
A：debug 签名的正常提示，选「仍然安装」。

**Q：怎么升级到新版本？**
A：用新 APK 覆盖安装（`-r` 参数），本地数据保留。

**Q：想给家人/多台手机用？**
A：当前版本**不支持多设备同步**（无账号体系）。可以用「我的 → 导出备份」手动传递。
